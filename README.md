# TF2Dump 64-bit (2026)

Дамп внутренних данных клиента Team Fortress 2 для 64‑битной версии игры.

## Что внутри

- `TF2Dump.json` (10.3 МБ) — структурированные данные в JSON.
- `TF2Dump.txt` (4.16 МБ) — читаемый текстовый вывод.

## Краткая статистика

- NetVars: 48 860
- Сигнатуры: 35
- Интерфейсы: 15
- Записи VTable: 884

## Для чего это

- Поиск офсетов и адресов функций.
- Разработка плагинов, модов или исследовательских инструментов.
- Изучение устройства движка Source (x64).

## Важно

- Данные актуальны для конкретного билда 2026 года. После обновления игры часть информации устареет.
- Использование в читерских целях нарушает пользовательское соглашение Valve и может привести к бану VAC.

## Как открыть

- `TF2Dump.txt` — любой текстовый редактор.
- `TF2Dump.json` — можно парсить скриптами (Python, JS и т.д.).
