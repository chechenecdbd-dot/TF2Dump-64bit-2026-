## 📂 Что внутри

- `TF2Dump.json` (10.3 МБ) — структурированные данные в формате JSON.
- `TF2Dump.txt` (4.16 МБ) — читаемый текстовый вывод.

## 🎯 Для чего это

- Поиск офсетов и адресов функций.
- Разработка плагинов, модов или исследовательских инструментов.
- Изучение внутреннего устройства движка Source (x64).

## ⚠️ Важно

- Данные актуальны для конкретного билда 2026 года. После обновлений часть информации устареет.
- Использование в читерских целях нарушает пользовательское соглашение Valve и может привести к бану VAC.
- Репозиторий предназначен **только для образовательных и исследовательских целей**.

## 🔧 Как использовать

- Откройте `TF2Dump.txt` любым текстовым редактором.
- Парсите `TF2Dump.json` с помощью скриптов (Python, JS и т.д.) для автоматизации.
